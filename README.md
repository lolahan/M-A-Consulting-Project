# AI License Renegotiation Tool

**Client**: Confidential (BTL Strategic Finance / Kopix)
**Consultancy**: True Clarity Consulting Ltd.

## Overview

This application is a specialized decision support tool designed to model and optimize the renegotiation of the AI technology license agreement between BTL and Kopix. It enables stakeholders to visualize the financial and operational trade-offs between different royalty structures, upfront fees, and exclusivity periods.

## Key Features

### 1. Financial Modeler (Deal Desk)
*   **Dynamic NPV Modeling**: Interact with key deal terms (Royalty Rate, Upfront Fee, Exclusivity) to see real-time impacts on Deal NPV, EBITDA Uplift, and Payback Period.
*   **Scenario Management**: Save, compare, and analyze multiple negotiation scenarios side-by-side.
*   **Valuation Modes**: Switch between "Target Revenue" (Deal input) and "Feasible Revenue" (Production constraint) to stress-test high-growth scenarios.

### 2. Production Optimiser (Operations)
*   **Capacity Simulation**: Discrete event simulation of the manufacturing line (Labour, Wafer Cutting, Assembly Lines).
*   **Constraint Analysis**: Identify bottlenecks (e.g., Labour hiring limits, Line 2 capacity) under different growth assumptions.
*   **Investment Planning**: Evaluate the ROI of CapEx interventions (e.g., Building Line 3, Upgrading Station B) to unlock AI production volume.

## Technology Stack

*   **Framework**: Next.js 14 (React)
*   **Styling**: Tailwind CSS
*   **Charts**: Recharts
*   **State Management**: Zustand
*   **Icons**: Lucide React

3.  Run the development server: `npm run dev`
